# Hero editorial — prototipo

Prototipo del hero «Suave como la caricia de mamá» (estructura del prompt MAREN de MotionSites, adaptada a Lion Cub). Spec: `docs/requisitos/hero-editorial-2026-11-04.md`.

- Abrir `index.html` en el navegador desde esta carpeta (usa las fotos de `public/`).
- Movimiento: viento en cortinas y plantas, brillo del mar (filtros SVG, solo escritorio), rayos de luz y motas de algodón (canvas). Todo se detiene con `prefers-reduced-motion`.
- Es referencia de diseño, no código de producción: la integración sigue el plan que se apruebe.
